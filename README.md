# De la prohibición del celular al laboratorio ampliado

Presentación de la **Actividad Obligatoria 4: De la planificación a la implementación**, de la materia **Prácticas en Tecnología Educativa** (Licenciatura en Tecnología Educativa, UTN), ciclo 2026.

Documenta una propuesta de acompañamiento tecnopedagógico para la enseñanza de Ciencias Naturales en una escuela secundaria técnica de gestión estatal. La escuela cuenta con laboratorios bien equipados, pero ante la dispersión del curso respondió prohibiendo el celular. La intervención sostiene que el problema no es el equipamiento sino la falta de una estrategia didáctica que dé sentido pedagógico a la tecnología disponible, y propone integrar el celular como instrumento de registro dentro del laboratorio.

La propuesta se trabajó como **ensayo simulado**: la planificación está completa, el diagnóstico se realizó en modo ensayo con evidencia real, y la implementación y la evaluación quedan pendientes.

## Cómo verla

Es un único archivo HTML, sin instalación ni dependencias (solo carga tipografías de Google Fonts). Abrí `Act4_equipo3_Arguello_Costas_Pedaci_presentacion.html` en cualquier navegador.

**En computadora** se ve como una presentación de diapositivas 16:9:

| Tecla | Acción |
|---|---|
| `→` `Espacio` `Enter` | Diapositiva siguiente |
| `←` `Retroceso` | Diapositiva anterior |
| `Inicio` / `Fin` | Primera / última diapositiva |
| `G` | Vista de cuadrícula |
| `N` | Notas del orador |
| `F` | Pantalla completa |

Cada diapositiva tiene su propio enlace (`#s1` a `#s19`), útil para compartir una en particular.

**En celular** la presentación pasa a un modo de lectura vertical con desplazamiento continuo, adaptado a pantallas angostas.

Las animaciones se desactivan si el sistema tiene activada la opción de reducir el movimiento.

### Publicarla con GitHub Pages

En *Settings > Pages*, elegí la rama principal como origen. Para que se abra directamente en la URL del sitio, renombrá el archivo HTML a `index.html`.
